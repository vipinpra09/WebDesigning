# WebDesigning

A collection of basic **Web Designing** practicals and HTML exercises created as part of web development coursework.

## About

This repository contains HTML pages and practical files covering common web-designing concepts such as navigation, login and registration forms, catalogue pages, shopping cart layouts, and academic department pages.

The main webpage is designed around **Raj Kumar Goel Institute of Technology (RKGIT)** and provides navigation to different sections including CSE, AIML, DS, and IoT. The homepage also uses an iframe to display linked pages within the main layout.

## Technologies Used

- HTML5
- Basic CSS / HTML styling
- HTML Tables
- HTML Forms
- Hyperlinks and Navigation
- Iframes

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/vipinpra09/WebDesigning.git
```

2. Open the project folder.
3. Navigate to the `WD` folder.
4. Open `index.html` in any modern web browser.

No server or external dependencies are required for the basic HTML pages.
