## Exercises

### Exercise 1 — Home Page

A basic homepage for **Raj Kumar Goel Institute of Technology (RKGIT)**. It includes navigation links for Login, Registration, Catalogue, Cart, and department pages such as CSE, AIML, DS, and IOT.

### Exercise 2 — Login Page

A simple login-page exercise using HTML. The folder also contains the related homepage and supporting HTML page files.

### Exercise 3 — Catalogue Page

A simple book catalogue created using an HTML table. It contains:

- Book cover placeholder
- Book name
- Author
- Publisher
- Price
- Add to Cart button

The catalogue currently includes books such as **XML Bible, AI, Java 2, and HTML in 24 Hours**.

### Exercise 4 — Cart Page

A simple shopping-cart page using an HTML table. It displays:

- Book name
- Author
- Price
- Quantity
- Total price
- Total amount
- Place Order button
- Reset button

## Technologies Used

- **HTML5**
- HTML Tables
- HTML Forms
- Hyperlinks
- Iframe/navigation concepts
- Basic HTML attributes

The current exercises intentionally use simple HTML so that the fundamental web-designing concepts are easy to understand and practice.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/vipinpra09/WebDesigning.git
```

2. Open the repository in VS Code or any other code editor.
3. Open any exercise folder.
4. Open the required `.html` file in a web browser.

No server or package installation is required for these basic HTML exercises.
